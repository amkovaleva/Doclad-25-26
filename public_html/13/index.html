2. Многоколоночный текст

Свойство column-count и column-gap для создания газетной верстки.

Многоколоночный текст позволяет контенту плавно перетекать из одной колонки в другую. Это свойство отлично подходит для длинных текстовых блоков, делая их более читабельными на широких экранах без лишнего нагромождения HTML-разметки. Здесь мы используем две колонки с расстоянием между ними 30px.

3. Клиппинг и маски

Ограничение видимости элемента с помощью clip-path и mask.

Клиппинг (слева): элемент обрезан до формы ромба с помощью polygon().
Маска (справа): градиентная маска создает эффект плавного исчезновения.

4. Кастомизация маркера списка (::marker)

Изменение стандартного маркера на любой символ или эмодзи.

  • Использование псевдоэлемента ::marker
  • Возможность вставки символов через content
  • Стилизация цвета и размера маркера
