Задание 3: Позиционирование

Время: 10-12 минут

Часть 1: Бейдж "NEW" должен быть в правом верхнем углу карточки.
Часть 2: Подсказка (tooltip) должна появляться над кнопкой при наведении.

HTML:

<div class="card"> <span class="badge">NEW</span> <p>Товар</p> <div class="tooltip-container"> <button>Наведи на меня</button> <span class="tooltip">Это подсказка!</span> </div> </div>

CSS (что есть):

.card { position: relative; border: 2px solid #333; padding: 20px; } .badge { background: #e74c3c; color: white; padding: 5px 10px; border-radius: 3px; /* Позиционируй в правый верхний угол */ } .tooltip-container { position: relative; display: inline-block; } .tooltip { background: #2c3e50; color: white; padding: 10px; border-radius: 5px; display: none; /* Позиционируй над кнопкой */ } .tooltip-container:hover .tooltip { /* Покажи при наведении */ }

Как это выглядит сейчас:

NEW

Товар
