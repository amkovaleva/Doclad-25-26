Что такое формы в Bootstrap?

Формы в Bootstrap — это набор стилей и компонентов для создания удобных, адаптивных и доступных форм. Они включают поля ввода, чекбоксы, радиокнопки, селекты, группы ввода и валидацию. Формы обеспечивают единый вид в разных браузерах и устройствах.

Bootstrap использует классы вроде form-control для стилизации элементов, делая их современными и отзывчивыми.

Обзор форм в Bootstrap

Формы строятся на классах вроде form-control для полей ввода, form-label для меток и form-text для подсказок. Например: 

<form>
  <div class="mb-3">
    <label for="exampleInputEmail1" class="form-label">Адрес электронной почты</label>
    <input type="email" class="form-control" id="exampleInputEmail1" aria-describedby="emailHelp" />
    <div id="emailHelp" class="form-text">Мы никогда не поделимся вашей почтой.</div>
  </div>
  <button type="submit" class="btn btn-primary">Отправить</button>
</form>

1. Элементы управления формами (Form Controls)

Класс form-control применяется к <input>, <textarea> и <select>. Поддерживает типы: text, email, password, number, file и т.д. Размеры: form-control-sm, form-control-lg. 

<input type="text" class="form-control" placeholder="Введите текст" />
<textarea class="form-control" rows="3"></textarea>

2. Выпадающие списки (Select)

Класс form-select для <select>. Поддерживает multiple, size, disabled. Размеры: form-select-sm, form-select-lg. 

<select class="form-select">
  <option selected>Выберите...</option>
  <option value="1">Один</option>
</select>

3. Чекбоксы и радиокнопки (Checks and Radios)

Класс form-check для чекбоксов и радиокнопок. Для свитчей — form-switch. Inline: form-check-inline. Без меток: используйте aria-label. 

<div class="form-check">
  <input class="form-check-input" type="checkbox" id="check1" />
  <label class="form-check-label" for="check1">Стандартный чекбокс</label>
  </div>

Варианты расположения и стилизации

Чекбоксы и радиокнопки можно располагать горизонтально, вертикально, делать кнопочного вида и использовать свитчи.

4. Ползунки (Range)

Класс form-range для <input type="range">. Поддерживает min, max, step, disabled. 

<input type="range" class="form-range" min="0" max="5" step="0.5" id="customRange" />

5. Группы ввода (Input Group)

Группы ввода позволяют добавлять текст, иконки, кнопки, выпадающие списки слева и/или справа от поля ввода. Классы: input-group, input-group-text. 

<div class="input-group">
  <span class="input-group-text">Область текста</span>
  <textarea class="form-control" aria-label="With textarea"></textarea>
</div>

7. Макеты форм (Layout) — подробный обзор

По умолчанию элементы форм (input, select, textarea) занимают 100% ширины родителя и располагаются вертикально. Для создания многостолбцовых, горизонтальных или адаптивных форм используется система сетки Bootstrap.

Сетка форм

Оборачивайте поля в .row и используйте .col-*. Горизонтальные отступы регулируются классами .g-* (gutters). 

<div class="bd-example">
    <div class="row g-3">
        <div class="col-md-6">
            <input type="text" class="form-control" placeholder="Имя" />
        </div>
        <div class="col-md-6">
            <input type="text" class="form-control" placeholder="Фамилия" />
        </div>
        <div class="col-12">
            <input type="email" class="form-control" placeholder="Email" />
        </div>
    </div>
</div>
Горизонтальные формы

Используйте класс .col-form-label для выравнивания меток по вертикали с полями.

Авторазмер колонок (.col-auto)

Колонка занимает ровно столько места, сколько нужно содержимому. Удобно для форм поиска, фильтров, логинов.

8. Валидация форм (Validation)

Bootstrap использует встроенную HTML5-валидацию + стили для состояний :valid / :invalid. Есть два основных подхода: клиентская (браузерная) и серверная.

Клиентская валидация (рекомендуемый способ)

Самый удобный вариант для пользователя: он ещё не отправил форму, а уже видит «Эй, тут забыли email» или «Пароль слишком короткий».

Что нужно сделать:

  1. Добавить на форму class="needs-validation" и атрибут novalidate (это отключает стандартные всплывающие окошки браузера).
  2. На обязательные поля навесить атрибут required, тип type="email", minlength и т.д. — браузер сам проверит.
  3. Под каждым полем добавить блок с сообщением об ошибке: <div class="invalid-feedback">Текст ошибки</div>
  4. Немного JavaScript, чтобы при отправке формы добавлялся класс was-validated — именно он включает красивые стили Bootstrap. 
<div class="bd-example">
    <form class="needs-validation" novalidate>
        <div class="mb-3">
            <label for="userEmail" class="form-label">Email</label>
            <input type="email" class="form-control" id="userEmail" required />
            <div class="invalid-feedback">Введите корректный email</div>
        </div>
        <div class="mb-3">
            <label for="userName" class="form-label">Имя</label>
            <input type="text" class="form-control" id="userName" required minlength="2" />
            <div class="invalid-feedback">Имя должно быть хотя бы из 2 букв</div>
        </div>
        <button class="btn btn-primary" type="submit">Отправить</button>
    </form>
</div>

<!-- JavaScript (обычно в конце страницы или в отдельном файле) -->
<script>
(() => {
  'use strict'
  const form = document.querySelector('.needs-validation')
  form.addEventListener('submit', event => {
    if (!form.checkValidity()) {
      event.preventDefault()
      event.stopPropagation()
    }
    form.classList.add('was-validated')
  }, false)
})()
</script>

После этого поле с ошибкой получит красную рамку, под ним появится сообщение, а если всё ок — зелёная рамка и галочка.

Серверная валидация

Если форма уже улетела на сервер, а там выяснилось, что логин занят или код неверный — сервер просто возвращает страницу с подсвеченными полями.

Как сделать:

  • К полю добавляем класс is-invalid (ошибка) или is-valid (всё хорошо).
  • Под полем — тот же invalid-feedback или valid-feedback.
  • Если поле внутри input-group — добавить класс has-validation на группу, иначе рамка может криво отображаться. 
<div class="bd-example">
  <div class="mb-3">
      <label for="login" class="form-label">Логин</label>
      <input type="text" class="form-control is-invalid" id="login" value="admin" />
      <div class="invalid-feedback">Такой логин уже занят, придумайте другой</div>
  </div>
</div>
Такой логин уже занят, придумайте другой
Где показывать сообщения: под полем или всплывашкой?
  • Обычный текст под полем — классы invalid-feedback / valid-feedback.
  • Всплывающая подсказка (tooltip) — классы invalid-tooltip / valid-tooltip. Нужно обернуть поле в <div class="position-relative">, подсказка появляется при наведении или фокусе. Используется в случаях, когда места мало.

9. Доступность и отключенные состояния

Bootstrap делает формы максимально доступными, но требует правильного использования атрибутов.

Отключенные поля и группы (disabled / readonly)

Есть три основных состояния:

  • disabled — поле полностью неактивно, не отправляется на сервер, выглядит серым и бледным
  • readonly — поле можно выделять и копировать, но нельзя редактировать, отправляется на сервер
  • <fieldset disabled> — отключает сразу всю группу полей
<div class="bd-example">
    <fieldset disabled>
        <legend>Отключенная группа</legend>
        <div class="mb-3">
            <label class="form-label">Имя</label>
            <input type="text" class="form-control" placeholder="Недоступно" />
        </div>
        <div class="form-check">
            <input class="form-check-input" type="checkbox" />
            <label class="form-check-label">Нельзя отметить</label>
        </div>
        <button type="submit" class="btn btn-primary">Отправить</button>
    </fieldset>
</div>
Отключенная группа

Доступность: метки и ARIA

ARIA (Accessible Rich Internet Applications) — это набор специальных HTML-атрибутов, которые помогают сделать веб-интерфейсы понятными для скринридеров и других вспомогательных технологий. Они не меняют внешний вид страницы, но сообщают программам чтения с экрана, что именно происходит: где метка, где ошибка, какое поле отключено и т.д.

  • Каждое поле ввода должно иметь понятную метку — лучше всего через <label for="id">. Если видимой метки нет (например, только иконка), используйте aria-label или aria-labelledby.
  • Подсказки, сообщения об ошибках и пояснения под полем связывайте с помощью aria-describedby="id-подсказки". Тогда скринридеры сразу озвучат важную информацию после поля.
  • Для отключённых кнопок и элементов (кроме обычного disabled) добавляйте: aria-disabled="true" и tabindex="-1" — чтобы их не фокусировали клавиатурой. 
<!-- Пример: поле + подсказка + ошибка -->
<input class="form-control is-invalid" id="email" aria-describedby="emailHelp emailFeedback">
<div id="emailHelp" class="form-text">Мы не передаём почту третьим лицам</div>
<div id="emailFeedback" class="invalid-feedback">Введите корректный email</div>

10. Настройка форм через Sass

Bootstrap написан на Sass, поэтому почти все параметры форм (отступы, цвета границ, размер шрифта, толщину фокусной обводки и т.д.) можно переопределить, не трогая основной код.

Самые часто меняемые переменные форм
Переменная Значение по умолчанию За что отвечает
$input-padding-y .375rem Вертикальный внутренний отступ поля
$input-padding-x .75rem Горизонтальный внутренний отступ
$input-font-size 1rem Размер текста внутри поля
$input-border-radius .375rem Скругление углов
$input-focus-width .25rem Толщина синей обводки при фокусе
$form-text-color #6c757d Цвет мелкого текста-подсказки
Простой пример кастомизации
// Перед импортом Bootstrap переопределяем нужные переменные
$input-padding-y:            .5rem;           // чуть выше поля
$input-padding-x:            1rem;            // шире поля
$input-font-size:            1.05rem;         // чуть крупнее текст
$input-focus-width:          .3rem;           // заметнее фокус
$input-focus-border-color:   #6f42c1;         // другой цвет обводки при фокусе

// Можно также поменять цвета валидации
$form-valid-color:           #198754;
$form-invalid-color:         #dc3545;

// Затем подключаем
@import "bootstrap/scss/bootstrap";
